GUADALUPE NHS - PPT REMOTE (WINDOWS)
====================================

BUILD THE APP (once)
1. Install Python 3 from python.org if you don't have it
   (tick "Add Python to PATH" during install).
2. Double-click build_windows.bat
3. When it finishes, your app is in the "dist" folder:
   Guadalupe NHS Remote.exe

USE THE APP
1. Open your PowerPoint presentation first.
2. Double-click "Guadalupe NHS Remote.exe"
   (if Windows SmartScreen warns: More info > Run anyway)
3. If Windows Firewall asks, click "Allow access".
4. Scan the QR code with your phone camera.
   (Phone and PC must be on the same Wi-Fi or hotspot.)
5. Type the PIN shown in the window.
6. Tick what the phone may do and tap Continue, then tap Start.
7. Click Stop when finished. A new PIN is made every time the app starts.
